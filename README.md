# Proyecto-1-Apps-Moviles
### App desarrollada en .NET MAUI, uso de C# y XAML.
La aplicación consiste en una interfaz simple que cuenta con un botón para generar un Codigo Hex aleatorio de un color RGB asi como sliders para editarlo.
